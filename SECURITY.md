# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in a public issue or pull request.
Use GitHub's private vulnerability reporting feature for this repository, if
available. If it is not available, contact the repository owner privately
through their GitHub profile.

Include the affected workflow or block, the commit or catalog version, the
impact, and steps to reproduce the issue. Avoid sharing real credentials,
tokens, or other sensitive data in a report; use redacted examples instead.

Please allow the maintainer time to investigate and coordinate a fix before
publishing vulnerability details. There is no guaranteed response or resolution
time.

## Scope

This policy covers security issues in this repository's block manifests and
reusable GitHub Actions workflows. For vulnerabilities in FlowAction or other
third-party services, please report them to the relevant project's maintainers.
